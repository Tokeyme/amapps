Privacy Policy for “Decision Maker” in your browser

Last updated: 3 November 2026

This privacy policy applies to the free browser version of the game “Decision Maker” at decision.amapps.app (the “game”), in all its languages: French “Le Décideur”, Spanish “El Decisor”, Japanese “決断者” and German “Entscheider”. For the embedded version on itch.io, see section 9, which also states which sections do not apply to it or apply only with changes. The Mac app “Entscheider” (“Decision Maker”) is covered by the app’s own privacy policy, and the website amapps.app by the website’s privacy policy (in German).

3. Key points in brief

  • There is no registration, no user account and no sign-in. There are no purchases and no advertising.
  • The site sets no cookies.
  • The game stores your game in progress, your saved games, your high-score list and your settings only in your browser on your device (section 6). The game sends none of this to any server, not even to the controller. Only the chosen language becomes visible as part of the address (section 6).
  • The site is hosted on GitHub Pages. The game engine, fonts, images and music all come from decision.amapps.app itself. When they are fetched, GitHub inevitably learns your IP address for technical reasons (section 4).
  • For audience measurement, the controller uses Cloudflare Web Analytics, without cookies and without recognising individual visitors. It tells him how often the site is visited and in which languages the game is played (section 5). Apart from this measurement script, the site loads nothing from third-party servers.
  • The game is also to be available embedded on itch.io; it has not been published there yet. There, itch.io is itself responsible for its site. The game stores data there only in your browser, and the controller does not count any visits there (section 9).
  • The controller does not sell any data and does not create usage profiles.
  • Where processing is based on legitimate interests, you can object to it at any time (section 15).

5. Audience measurement (Cloudflare Web Analytics)

The controller would like to know whether the browser version is being played, and in which languages. For this, as on amapps.app, he uses Cloudflare Web Analytics, a service of Cloudflare, Inc. (USA).

  • How: Each language page (/de/, /en/, /fr/, /es/, /ja/) loads a small measurement script from Cloudflare (static.cloudflareinsights.com) when it is opened. The script reports the visit to Cloudflare (cloudflareinsights.com). The start page, which only forwards you to the matching language page, does not contain it, and neither do the error page and the version on itch.io (section 9). If the address brings a move along (section 8), the language page does not load the measurement script at all. If you change the language in the game, the game changes the language part of the address without reloading (for example from /de/ to /fr/). The measurement script does not count this as a further visit. A reload, and your next visit via the start page, lead to the page of the chosen language; the script counts these visits. This shows which languages the game is played in.
  • What is collected: The tool works without cookies and without recognising individual visitors. It sets no cookies, stores no identifier in your browser and creates no cross-device profiles. It collects the page visited, the approximate origin (country), the referring source (referrer), browser and operating system including their versions, the device type (computer, phone, tablet) and technical performance values that the script reads in the browser: how quickly the page loads and responds to input, whether the layout shifts and, in Chromium-based browsers, how much memory the page uses. It also names the element of the page concerned and, for input, whether it came from the keyboard or from a click or tap. The script removes the part of the address after “?” and after “#” before reporting. When the script is loaded and when it reports, Cloudflare also inevitably learns your IP address and the information your browser sends, for technical reasons.
  • What the controller sees: only aggregated figures. He cannot recognise individual visitors in them. He uses the figures only to follow the number of visits and the languages played. There is no further analysis, no advertising and no sharing.
  • Processor: Cloudflare processes the measurement data on behalf of the controller; the data processing agreement (Art. 28 GDPR) is part of Cloudflare’s terms. Cloudflare’s Privacy Policy applies.
  • Legal basis: Art. 6(1)(f) GDPR; the legitimate interest lies in finding out, with a data-minimising tool without cookies, whether and in which languages the free browser version is used. You can object to the measurement at any time (section 15).
  • Third country: Cloudflare is certified under the EU-U.S. Data Privacy Framework. The transfer is therefore based on the European Commission’s adequacy decision (Art. 45 GDPR).
  • Retention: According to Cloudflare’s own information, Cloudflare keeps the individual reports in full for seven days and after that only in condensed form (around 10% of the data volume); the figures can be viewed for the previous six months. Cloudflare does not state there how long it keeps the IP address from fetching the script and from the report.
  • Preventing it yourself: If your browser or a content blocker blocks the script from static.cloudflareinsights.com, no measurement takes place. The game still works.

6. Storage in your browser

So that you can carry on where you left off, the game stores a number of entries in your browser’s local storage (localStorage) for decision.amapps.app. These entries stay on your device. The game sends them to no server, and the controller has no access to them. Only the chosen language becomes visible as part of the address (see below). The entries contain no information about you as a person; the game has no input fields for names or other text.

The following is stored (the keys begin with flutter.entscheider.):

  • The game in progress and the point where you are in it, so that your next visit continues there.
  • Up to three saved games, if you create them.
  • Your high-score list with the results of your games. Each game carries a random identifier for this, so that it appears in the list only once.
  • The language you have chosen in the game.
  • The radio settings: station, volume and, for each station, a starting time for its programme.
  • Saved games set aside: If the game cannot read a stored game or the high-score list, for example because it comes from a newer version, it sets it aside unchanged instead of deleting it.
  • One technical flag: a random identifier of the browser tab that is currently playing. That way, two open tabs do not overwrite each other’s game.

If you chose “Play anyway” on a small screen, your browser also remembers this under the key entscheider.web.trotzdem. That way the notice does not appear every time.

Persistent storage: So that the browser does not delete your saved games on its own, the game checks at every start whether the browser already keeps this site’s storage permanently. If not, it asks the browser to do so. The game asks Chrome, Edge and other Chromium-based browsers at every start; they decide this themselves without asking you. In other browsers, the game only asks when you choose “Save to file”, and at most once per visit; Firefox then shows you a prompt. Whether you agree is up to you. The game also works without it. The game does not store the browser’s answer.

If the browser does not store anything: If site data is blocked or the storage is full, the game still works. However, your game in progress is then lost as soon as you close or reload the page. The game tells you so once per visit to the page (“Unable to save”) and points you to “Save to file” (section 7). The “Saved games” panel also reports it if it cannot store a saved game. The game keeps the fact that the notice has already been shown only in its working memory, not in your browser.

Other checks in the browser: The page checks the width of the window, the size of the screen and the type of pointing device, so that it can show a notice on small screens before loading; this check stays in the browser. As long as the browser does not keep this site’s storage permanently, the game also checks whether it is running in a Chromium-based browser (only whether the navigator.userAgentData property exists, not its content), to decide when to ask for persistent storage; this, too, stays in the browser. Flutter, the framework the game is built with, also reads some details about the browser, operating system and touch support when the page loads (navigator.userAgent, navigator.platform, navigator.maxTouchPoints and navigator.vendor), in order to choose the right display and controls; this, too, stays in the browser. So that the game starts in your language, the start page reads the language you chose in the game from your browser or, if you have not chosen one, the list of your preferred languages. The language then becomes part of the address: the start page forwards you to /de/, /en/, /fr/, /es/ or /ja/. Your browser requests this address from GitHub (section 4), and the audience measurement records it (section 5).

Deletion: You remove all these entries by clearing the site data for decision.amapps.app in your browser. There is nothing to delete on the controller’s side. In a private window, the browser deletes the entries as soon as you close it. If you want to keep your saved games, save them to a file first (section 7).

Legal basis: The controller does not receive this data. Where it contains personal data at all, storing it serves to provide the game you are using (Art. 6(1)(b) GDPR).

Storing and reading information in your browser (§ 25 TDDDG): The game stores the entries listed above in your browser and reads them back; the start page reads the chosen language. The page also reads the window width, screen size, pointing device, language list and the browser and device details used for display, checks whether it is a Chromium-based browser and asks the browser whether it keeps this site’s storage permanently. This is strictly necessary for the game to provide the functions you expressly use: displaying the game in your browser, continuing your game, saved games, the high-score list, keeping unreadable saves, language, the radio, the small-screen notice, protecting your saved games from being deleted by the browser on its own, and protecting your game when several tabs are open (§ 25(2) no. 2 of the German Telecommunications Digital Services Data Protection Act, TDDDG).

7. Backup file

Under “Saved games”, you can create a backup file with “Save to file”. For this, the game takes the game in progress directly as it currently holds it, not from your browser’s storage. This also works if the browser does not allow storing. Your browser creates the file on your device and stores it like a download, usually in the “Downloads” folder. It contains the game in progress and, as far as your browser allows them to be read, the saved games, the high-score list, any saved games set aside, the chosen language and the radio station and starting times, but neither the volume nor the technical flag. With “Load from file”, you choose such a file; the browser reads it only on your device. In both cases, nothing goes to a server. What you do with the file, for example whether you pass it on, is up to you.

8. Moving to another address

Should the game ever move to another address, it takes your saved games along. The old address reads them in your browser and passes them on in the last part of the new address, after the “#” character. Your browser does not send this part to the server when it fetches a page. If it begins with “umzug=”, the language pages of decision.amapps.app do not load the Cloudflare measurement script (section 5) at all; this visit is therefore not counted. The new address imports the saved games in your browser and removes this part from the address straight away. That way, neither a reload nor a bookmark carries it along. The technical flag and the volume are not passed on. If the data is too large, the old address only offers it as a file. If it has already been passed on once, the old address no longer forwards you on its own but offers both: the way to the new address and the file. The old address remembers in your browser that it has passed the data on. The old address keeps your saved games; you remove them there by clearing the old address’s site data.
